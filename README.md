# Olist E-Commerce Business Intelligence Analysis

## Business Problem
How do delivery performance, customer satisfaction, payment behavior, and product categories affect e-commerce revenue?

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- Matplotlib
- GitHub

## Dataset
Olist Brazilian E-Commerce Dataset

## Key Results
- Total Revenue: 20.42M
- Total Orders: 98,665
- Average Review Score: 4.03
- Late Delivery Rate: 6.53%

## Key Insights
- Late deliveries reduce review score from 4.18 to 2.20.
- Credit card generates the majority of revenue.
- Bed Bath Table is the highest revenue category.
- SP is the highest revenue-generating state.
- AL has the highest late delivery rate.

## Business Recommendations
- Reduce late deliveries.
- Focus on high-performing categories.
- Improve logistics in high-delay states.
- Monitor customer satisfaction closely.
